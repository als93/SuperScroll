# Changelog

All notable changes to SuperScroll are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-28

### Added
- Toolbar popup with Start / Stop
- Automatic scrolling to the bottom of the page and inside scrollable containers
- Detection and clicking of “Load more”-style buttons in 11 languages
- Live on-page progress badge with Stop button
- Settings: wait time, idle rounds, max runtime, max clicks, button clicking toggle, custom CSS selector
- Demo page with “Load more” and infinite-scroll modes
